Use premium-ui-stack, UI Doctrine, UX Laws and the established Yokogawa/BioPilot treatment. Retain approved logo, system typography, navy/blue palette, subtle grid and result hierarchy. This is a focused density refinement, not a new design direction.

Intended cue: compact and approachable; the job is evident immediately. Journey: bold subheading → selected bottleneck → grey examples alongside persistent labels → entered values → clear result → deeper assessment.

Concrete treatment: shorter header; reduced hero/tabs/column gaps; 44–48px controls, smaller consistent radii and result padding. Dark semibold subheading. Grey e.g. placeholders distinguished from dark entered values. Conditional 44px X buttons with explicit accessible names and visible focus; unit text moves left of clear control. Preserve helpers and validation.

Validation: same viewport/state before/after screenshots, desktop primary-action coordinates, narrow 390px mobile overflow, all lanes, clear/focus/validation recovery, optional assumptions and readable target bounds. User feedback motivates this change; conversion improvement remains an untested hypothesis. Existing exception: anonymous-stage analytics remains deferred to avoid introducing data capture in this revision; observe future client feedback and consider privacy-compatible metrics separately.
