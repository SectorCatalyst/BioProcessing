## Example state
Untouched lane: Example values. Partly edited lane: Includes example values. All three fields edited: Your process data. This status follows the actual edited-field set, not merely whether one field was touched. Expanded assumptions keep corresponding example context.

## Recovery and continuity
Input/range errors direct clients to the fields or range needing correction; values remain in memory. Lane switching retains entries; reload resets them. Assumptions remain inspectable/editable, and zero remains valid. No additional step or contact gate is added (CP-002/004).
